# Avail Deposits — landing page (v2)

Static, single-page site. Live at https://rochelle-alfonso.github.io/avail-deposits-v2/

- `index.html`: the whole page, with styles and scripts inline
- `media/`: funding films (`-1350` for desktop, `-720` for phones, with matching `.webp` posters), the AI Skills / SDK docs films, and the Widget Configurator demo (`configurator.html`)
- `media/img/`: WebP images (`-NNN` suffixes are the phone-sized `srcset` variants)

GitHub Pages serves `main` from the repo root. Any push to `main` is live in about a minute.
